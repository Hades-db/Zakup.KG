# Набор для Figma — приложение поставок

## Что внутри

| Папка / файл | Что это |
|---|---|
| `svg/` | 16 экранов, каждый отдельным SVG (390 × 844). В Figma открываются слоями: текст остаётся текстом, иконки — векторами. |
| `png/` | Те же экраны картинками (@2x) — для быстрого просмотра и сравнения. |
| `icons/` | 18 иконок по отдельности, 24 × 24, линия 2 px. |
| `prototip.html` | Живой прототип с анимациями — открыть в браузере. |

## Как перенести в Figma

1. Откройте файл в Figma и перетащите все файлы из `svg/` на холст (или File → Import).
2. Каждый экран появится отдельной группой. Выделите группу и нажмите **Ctrl/Cmd + Alt + G** (Frame selection), чтобы превратить её во фрейм.
3. Шрифт **Manrope** в Figma уже есть. Если текст показывается другим шрифтом, выберите слой и поставьте Manrope вручную.
4. Иконки из `icons/` удобно сразу сделать компонентами (выделить → **Ctrl/Cmd + Alt + K**).

Альтернатива: плагин **html.to.design** умеет импортировать `prototip.html` целиком с автолейаутом. Удобно, если SVG-слои покажутся неаккуратными.
