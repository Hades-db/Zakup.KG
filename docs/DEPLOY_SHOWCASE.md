# Версия для показов на своём домене (шаг А1)

Версия для показов — это статичные файлы из папки `release/`, сервер ей не нужен. Хватает любого хостинга, который отдаёт файлы по HTTPS.

## Что нужно сделать вам

1. **Домен.** Зарегистрировать `zakup.kg` у регистратора доменов .kg.
2. **Хостинг в КР.** Подойдёт самый простой виртуальный сервер или хостинг для сайтов у провайдера в Кыргызстане: 1 ядро, 1 ГБ памяти, 10 ГБ диска.
   - Позже на этом же сервере можно держать GlitchTip и тестовый API, но для рабочей версии лучше отдельный сервер (шаг Б5).
3. **DNS.** У регистратора направить домен на IP сервера. Нужны две A-записи:

   | Имя | Тип | Значение |
   |---|---|---|
   | `zakup.kg` | A | IP сервера |
   | `admin.zakup.kg` | A | IP сервера |

   Позже будет нужен `api.zakup.kg`.

## Установка на сервер (Ubuntu 22.04 / 24.04)

```bash
# 1. Веб-сервер и сертификат
sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx

# 2. Файлы. Собрать на своём компьютере: python3 tools/build_release.py
#    Скопировать на сервер:
rsync -av --delete release/ user@SERVER:/var/www/zakup/

# 3. Настройка nginx
sudo tee /etc/nginx/sites-available/zakup <<'NGINX'
server {
    server_name zakup.kg www.zakup.kg;
    root /var/www/zakup;
    index index.html;
    location = /sw.js { add_header Cache-Control "no-cache"; }
    location ~* \.(png|jpg|svg|js|webmanifest)$ { expires 7d; }
}
server {
    server_name admin.zakup.kg;
    root /var/www/zakup;
    index admin.html;
    # доступ к админке только из офиса: подставьте свой IP
    # allow 1.2.3.4; deny all;
}
NGINX
sudo ln -s /etc/nginx/sites-available/zakup /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 4. HTTPS (Let's Encrypt, бесплатно, продлевается сам)
sudo certbot --nginx -d zakup.kg -d www.zakup.kg -d admin.zakup.kg
```

После этого откройте:
- `https://zakup.kg`: приложение, его можно установить на телефон или ПК;
- `https://admin.zakup.kg`: админка.

## Обновление

```bash
python3 tools/build_release.py
rsync -av --delete release/ user@SERVER:/var/www/zakup/
```

У service worker при каждой сборке новая версия, поэтому у пользователей обновление подтянется при следующем открытии.

|---|---|---|
| Магазин «Айдана» | +996 700 000 111 | demo1234 |
| Поставщик ОсОО «Дистрибьютор» | +996 700 000 101 | demo1234 |
| Доставщик Эрлан Касымов | +996 700 000 102 | demo1234 |
| Доставщик Бекзат Осмонов | +996 700 000 103 | demo1234 |
| Доставщик Улан Токтогулов | +996 700 000 104 | demo1234 |
| Админка | +996 500 99 16 20 | любой, код — любые 6 цифр |

- Номера вымышленные. Такие же номера в демо-данных базы (`db/seed.sql`).
- Новые доставщики, которых добавляет поставщик, входят по номеру и паролю, указанным при добавлении.
- Зарегистрированная компания входит после подтверждения в админке.
- После сброса пароля в админке пользователь входит с временным паролем.
- Данные хранятся в браузере. Админка видит изменения приложения, только если обе открыты в одном браузере на одном устройстве.
